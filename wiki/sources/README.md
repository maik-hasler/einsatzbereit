# sources/

Your own loose notes and ideas about Einsatzbereit - drop them here as plain
Markdown or text (e.g. `2026-07-16-idea.md`). Read-only by convention once
added: never edit or delete a file here to "correct" it after the fact - if a
later note contradicts an earlier one, drop the new note anyway and let
`/wiki:ingest` handle the supersession in `wiki/`, not here.

This is one of three input channels for this wiki - see `../README.md` and
`../AGENTS.md` for the other two (the repo itself, GitHub issues/PRs).

After dropping something here, run `/wiki:ingest <path>` (or bare
`/wiki:ingest` for a full coverage pass) to have it read and distilled into
`wiki/`.
